🔷 YASGUI TABLE Plugin Demo

▼ 📖 Features & Instructions

  • 🚀 Virtual Scrolling: Efficiently handles 10,000+ rows with smooth performance
  • 🔍 Search & Filter: Type in the search box to filter rows in real-time
  • 📊 Column Management: Click headers to sort, drag edges to resize columns
  • 🎨 Display Controls: Toggle between full/abbreviated URIs, show/hide datatypes, enable ellipsis mode
  • 📋 Selection & Copy: Click cells to select, Ctrl+C to copy as TSV, Esc to clear
  • 💾 Export: Export table as Markdown, CSV to clipboard, or download CSV file
  • 🎯 SPARQL-Aware: Proper rendering of URIs, literals with datatypes, and blank nodes
  • Sample Queries: Try DBpedia (people), Wikidata (cities), or Custom endpoint queries
