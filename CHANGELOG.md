# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-11

### Added
- Initial release of YASGUI Table Plugin
- Virtual scrolling for 10,000+ rows
- Search and filter with highlighting
- Column sorting and resizing
- URI display controls (full/abbreviated)
- Datatype display toggle
- Cell content ellipsis with modal expansion
- Cell and row selection
- Clipboard copy (tab-separated values)
- Export to Markdown, CSV, TSV formats
- Theme integration with YASGUI
- localStorage persistence for user preferences
- Keyboard navigation support
- WCAG AA accessibility compliance
- Browser compatibility: Chrome, Firefox, Safari, Edge (latest 2 versions)
